## dbt packages

Packages are external dbt projects we can install into our own projects and reuse for various functionalities. Here is the dbt packages hub homepage.

{% include bbz_custom/link_preview.html url='<https://hub.getdbt.com/>' %}

And we are going to use some package right now.

### 1. define packages

Start from creating `packages.yml`{: .filepath} in the root folder as same as `dbt_project.yml`{: .filepath} as the example below.

{: file='packages.yml'}

```yaml
packages:
  - package: dbt-labs/dbt_utils
    version: 1.1.0
```

### 2. install packages

Execute the command [`dbt deps`](https://docs.getdbt.com/reference/commands/deps) to install and update packages according to `packages.yml`{: .filepath}

```sh
$ dbt deps
```

That's a prompt saying new version of dbt packages is available and we can update in `packages.yml`{: .filepath}.

### 3. make use of the packages

Right now we have `dbt-labs/dbt_utils` package. The package provides plenty of useful functions.

For example, `dbt_utils.not_null_proportion` is to verify if number of not-null in the field is in the given range. And we are checking if "not null" values are 95% or more as below.

```yaml
version: 2

models:
  - name: calc_grades
    columns:
      - name: id
        tests:
          - dbt_utils.not_null_proportion:
              at_least: 0.95
      - name: name
      - name: subject
      - name: grade
      - name: updated_at

```

Run `dbt test` and found it failed because number of "null" values are more than 5% in the field `id`.

## Interesting packages

These are some dbt packages that we can consider to use in our projects. Also much more to discover in the hub link above.

- [dbt-labs/codegen](https://github.com/dbt-labs/dbt-codegen) generate dbt code.
- [brooklyn-data/dbt_artifacts](https://github.com/brooklyn-data/dbt_artifacts) modelling dbt metadata.
- [dbt-labs/dbt_utils](https://github.com/dbt-labs/dbt-utils) Utility functions for dbt projects.
- [elementary-data/elementary](https://github.com/elementary-data/dbt-data-reliability) detect anomalies, monitor data quality, and build metadata tables.
- [metaplane/dbt_expectations](https://github.com/metaplane/dbt-expectations) deploy GE-like tests in their data warehouse directly from dbt.
- [dbt-labs/dbt_external_tables](https://github.com/dbt-labs/dbt-external-tables) dbt macros to stage external sources.
- [kristeligt-dagblad/dbt_ml](https://github.com/kristeligt-dagblad/dbt_ml) train, audit and use BigQuery ML models.
